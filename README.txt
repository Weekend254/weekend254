WEEKEND 254 — STARTER WEBSITE

This starter is a simple responsive website preview.
The activity cards are DEMONSTRATION CONTENT only. They are not verified
current events, prices, opening hours, or booking availability.

UPLOAD TO GITHUB
1. Open https://github.com/AceMau/weekend254
2. Choose Add file > Upload files.
3. Upload index.html to the repository root (not inside another folder).
4. Commit the changes.

PUBLISH WITH GITHUB PAGES
1. Open repository Settings.
2. Choose Pages in the left menu.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait for GitHub Pages to publish the site.
6. The address should be https://acemau.github.io/weekend254/

Replace demonstration listings with verified information before relying on them.
